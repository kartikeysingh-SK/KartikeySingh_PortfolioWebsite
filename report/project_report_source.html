1. Introduction & Project Objectives

1.1 Introduction

In the modern software engineering landscape, a personal developer portfolio serves as the definitive digital resume and technical identity for aspiring computing professionals. Rather than relying solely on static paper resumes, a well-crafted web portfolio demonstrates practical mastery over core frontend technologies, user experience design principles, responsive web layouts, accessibility standards, and professional version control workflows.

This project, titled Personal Portfolio Website, was designed and implemented as an academic mini-project for the subject IT4048: Version Control with Git and GitHub at Asha M. Tarsadia Institute of Computer Science and Technology (AMTICS). The website provides a modern, fast-loading, and visually captivating presentation of Kartikey Singh's academic profile, technical skill competencies, completed projects, and downloadable curriculum vitae.

1.2 Primary Objectives

The core objectives achieved in this project include:

  • Professional Digital Presentation: Presenting student information, technical proficiencies, engineering habits, and real-world projects in a structured, elegant manner.
  • Design Excellence & Custom Aesthetic: Implementing a premium dark-themed design system with electric blue and violet accents, glassmorphic cards, readable typography (Plus Jakarta Sans & JetBrains Mono), and fluid transitions without relying on generic frameworks or bloat.
  • Light & Dark Theme Architecture: Providing seamless light and dark mode toggling using CSS custom properties with automatic localStorage persistence.
  • Mobile-First Responsiveness: Ensuring complete usability across mobile devices (320px–480px), tablets (768px–1024px), and large desktop displays.
  • Version Control Mastery (IT4048): Implementing structured Git version control practices, including atomic semantic commit histories, clean branch management, repository tagging, and continuous deployment via GitHub Pages.
  • Zero Backend Hosting Compatibility: Architecting the application as a purely static site compatible with free GitHub Pages hosting, including a validated client-side contact form with mailto fallback and vector PDF resume download.

3. Git & GitHub Version Control Pipeline

3.1 Version Control Methodology (IT4048 Core)

Version control is the discipline of managing changes to software source code over time. For this mini-project, Git version 2.55 was utilized to track incremental project evolution from ground zero to the final published application.

3.2 Commit History & Semantic Conventions

To ensure professional traceability, commits adhere to the Conventional Commits standard. Every commit clearly specifies its type and scope:

  • feat(structure): initialize semantic HTML5 portfolio foundation
  • style(design): implement dark/light custom property design system
  • feat(interactivity): implement theme switcher, mobile drawer, and modal engine
  • feat(resume): generate vector resume PDF and download assets
  • test(qa): conduct browser automation, cross-viewport tests, and visual capture
  • docs(report): compile comprehensive academic report and submission README

3.3 Deployment Pipeline (GitHub Pages)

The project leverages GitHub Pages for continuous static delivery. The deployment workflow operates as follows:

Continuous Deployment Flow:
Local Workspace (Scratch) → Git Staging (git add) → Semantic Commit (git commit) → Push to GitHub (git push origin main) → GitHub Pages Automated Environment Build → Live HTTPS Distribution at:
https://kartikeysingh-SK.github.io/KartikeySingh_PortfolioWebsite/
